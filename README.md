Excited to share my latest end-to-end database & analytics project: **University Academic & Performance Management System** 🎓📊

Managing student performance, departmental rankings, and academic records across thousands of students requires a robust relational architecture and real-time analytical pipeline. I designed and built this system from scratch to bridge database engineering with interactive business intelligence.

---

### 🛠️ Key Highlights & Technical Stack:

🔹 **Relational Data Modeling (3NF):** Designed a normalized MySQL schema comprising 6 core entities (`Students`, `Courses`, `Departments`, `Instructors`, `Sections`, and `Enrollments`) with strict foreign key constraints and data integrity checks.

🔹 **Automated ETL Pipeline:** Synthesized and ingested 1,500+ referentially intact academic records using Python (`Faker`, `SQLAlchemy`, `PyMySQL`).

🔹 **Advanced SQL & Analytics:** Wrote optimized MySQL 8.0 Views, CTEs, and Window Functions (`DENSE_RANK`, `PARTITION BY`) to compute credit-weighted CGPAs, student department ranks, and attendance thresholds.

🔹 **Interactive Frontend Portal:** Built an interactive web dashboard using **Streamlit** for real-time student transcript lookup, department leaderboards, and attendance shortage alerts (<75%).
